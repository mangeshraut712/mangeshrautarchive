# Apple Human Interface Portfolio Design System

> For the comprehensive, full-length Design System specification, see **[docs/DESIGN.md](docs/DESIGN.md)**.

## Quick Summary

- **Primary Action Buttons**: Solid Apple Blue (`#0071e3`, hover `#0077ed`, active `#0062c4`). Zero shining animations or multi-stop gradients.
- **Secondary Buttons**: Light frosted (`#f2f2f7`, hover `#e5e5ea`) / Dark card (`#1c1c1e`, hover `#2c2c2e`).
- **Modal Close Buttons**: Unified 32px circular Apple Red (`#ff3b30`, hover `#ff453a`) with clean vector icon.
- **Active Chips / Filters**: Solid Apple Blue (`#0071e3`) with pure white text (`#ffffff`).
- **Cards & Surfaces**: Apple glassmorphism (`backdrop-filter: blur(20px)`) + 1px border highlight.
- **Typography**: SF Pro Display (headings) / SF Pro Text (body) / SFMono (code).
- **Anti-Patterns**: No `@keyframes` button shine overlays, no gradient text fills, no colored borders.
